# data/

Raw and derived datasets live here and are **never committed** (see `.gitignore`).

Use this directory for local caches and working tiles only. Anything that must be
shared goes through provenance-tracked snapshots described in
[`docs/01-architecture.md`](../docs/01-architecture.md) and
[`docs/03-data-sources.md`](../docs/03-data-sources.md).
